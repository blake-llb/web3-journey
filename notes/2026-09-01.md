### QueryClient 缓存层配置（react-query）

```typescript
new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5000,    // 数据被视为"新鲜"的时长（5 秒内重复读同一数据，不重新发请求）
      gcTime: 10000,      // 缓存数据无引用后，多久被 GC 回收清理（毫秒）
    },
  },
})
```

### wagmi createConfig 顶层字段汇总

```typescript
createConfig({
  chains: [...],        // 你要支持哪些网络（链），如 [mainnet, sepolia, base]
  transports: {...},    // 每条链用什么方式连：HTTP / WebSocket / IPC（传输层）
  connectors: [...],    // 用户连接钱包的方式：injected / metaMask / walletConnect / coinbase 等
})
```

### transports（传输层）配置

```typescript
import { http, webSocket, fallback } from 'wagmi'

transports: {
  [mainnet.id]: http('https://eth.merkle.io'),   // 默认 HTTP 传输（最常用）
  [sepolia.id]: http('https://rpc.sepolia.org'), // 测试网也可走 HTTP
  [polygon.id]: webSocket('wss://polygon-rpc.com'), // WebSocket：支持订阅事件、监听新区块
}
```

各传输方式对比：

| 方式 | 优势 | 特点 / 适用场景 |
|---|---|---|
| `http(url)` | 简单、稳定、兼容性好 | 适合绝大多数 dApp，单次请求/响应模式 |
| `webSocket(url)` | 支持事件订阅（新区块、log） | 需要 `watch` 事件、实时推送时使用 |
| `http()` 不传参 | 自动用 `chain.rpcUrls.default.http[0]` | 快速接入，但依赖 wagmi 内置 RPC（可能限流） |
| `fallback([httpA, httpB])` | 主备切换，提升稳定性 | 多 RPC 节点轮询，单点故障时自动降级 |
| `custom(provider)` | 完全自定义 EIP-1193 provider | 接入自建节点、私有链、本地 anvil/hardhat |

进阶示例：

```typescript
transports: {
  // 多 RPC 备份，自动切换
  [mainnet.id]: fallback([
    http('https://eth.merkle.io'),
    http('https://cloudflare-eth.com'),
  ]),
  // 订阅事件用 WS，读取数据用 HTTP（混合）
  [base.id]: fallback([
    http('https://mainnet.base.org'),
    webSocket('wss://base-mainnet.g.alchemy.com/v2/xxx'),
  ]),
  // 本地开发
  // [hardhat.id]: http('http://127.0.0.1:8545'),
}
```

### connectors（连接器）配置

```typescript
import { injected, walletConnect, coinbaseWallet } from 'wagmi/connectors'

connectors: [
  injected(),                              // 浏览器注入的钱包（MetaMask/Rabby/OKX）
  walletConnect({ projectId: 'YOUR_ID' }), // WalletConnect v2（手机钱包扫码）
  coinbaseWallet({ appName: 'My dApp' }),  // Coinbase Wallet
]
```

各连接器对比：

| 连接器 | 作用 | 是否需要额外配置 |
|---|---|---|
| `injected()` | 检测 `window.ethereum`（MetaMask/Rabby/OKX/Brave 等） | ❌ 无 |
| `walletConnect({ projectId })` | WalletConnect v2 协议，支持手机钱包扫码 | ✅ 需要 WalletConnect Cloud 申请 projectId |
| `coinbaseWallet({ appName })` | Coinbase Wallet 浏览器扩展 + 移动端 | ⚠️ 可选：appLogoUrl |
| `safe()` | Safe（多签钱包）登录 | ❌ 无 |
| `metaMask()` | 显式声明 MetaMask（EIP-6963 多钱包场景） | ⚠️ 可选：dappMetadata |
| `mock()` | 仅测试用，模拟钱包 | ❌ 无，配合 `wagmi/test` |

进阶示例：

```typescript
connectors: [
  // 1. 浏览器注入钱包（最常见）
  injected({
    shimDisconnect: true, // 让 dApp "断开连接"时真的清掉钱包权限
  }),
  // 2. WalletConnect：手机端钱包（imToken/Trust/Math 等）
  walletConnect({
    projectId: 'abc123...',   // 必填，WalletConnect Cloud 申请
    showQrModal: true,        // 是否弹官方扫码框
    metadata: {               // 自定义展示信息
      name: 'My dApp',
      description: 'My Web3 App',
      url: 'https://mydapp.com',
      icons: ['https://mydapp.com/logo.png'],
    },
  }),
  // 3. Coinbase Wallet
  coinbaseWallet({
    appName: 'My dApp',
    appLogoUrl: 'https://mydapp.com/logo.png',
  }),
  // 4. 强制指定 MetaMask（避免和其他钱包冲突）
  metaMask({
    dappMetadata: {
      name: 'My dApp',
      url: 'https://mydapp.com',
    },
  }),
]
```

### 完整 createConfig 示例（带注释）

```typescript
import { createConfig, http, webSocket, fallback } from 'wagmi'
import { mainnet, sepolia, base, polygon } from 'wagmi/chains'
import { injected, walletConnect, coinbaseWallet } from 'wagmi/connectors'

export const config = createConfig({
  // 1. 支持哪些链
  chains: [mainnet, sepolia, base, polygon],

  // 2. 每条链用什么方式连
  transports: {
    [mainnet.id]: fallback([ // 多 RPC 备份
      http('https://eth.merkle.io'),
      http('https://cloudflare-eth.com'),
    ]),
    [sepolia.id]: http('https://rpc.sepolia.org'),
    [base.id]: webSocket('wss://base-mainnet.g.alchemy.com/v2/xxx'), // WS 订阅
    [polygon.id]: http(), // 用内置 RPC
  },

  // 3. 用户连接钱包的方式
  connectors: [
    injected({ shimDisconnect: true }),
    walletConnect({
      projectId: 'YOUR_PROJECT_ID',
      metadata: { name: 'My dApp', url: 'https://mydapp.com' },
    }),
    coinbaseWallet({ appName: 'My dApp' }),
  ],

  // 4. （可选）SSR 相关
  ssr: true, // Next.js / Nuxt 等 SSR 框架需要
  batch: {   // 批量请求优化（multicall）
    multicall: { batchSize: 8_192 },
  },
})
```

补充几个小点：

- `staleTime` 决定"还要不要再请求链上"；`gcTime` 决定"内存里要不要清掉"。前者小、后者大是常规配置思路。
- `blockTime` 只是 wagmi 内部用来估算 `useWaitForTransactionReceipt` 等场景的预期出块时间，不会影响真实链行为。
- `multicall3`：wagmi 在批量读取（如 `useReadContracts`、多个 `useBalance`）时默认走 multicall3 合并请求，省 RPC 次数。
