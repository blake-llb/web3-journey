# NewDeposit
1. ETH单位，链上获取的是wei，比如获取eth和weth，页面需要展示eth（1wei=1wei）ETH = 10的18次方 wei，parseFloat(formatEther(ethBalance.value)).toFixed(4)
2. viem里面有转换方法，formatEther(wei)以及parseEther(eth)，用户输入的eth，需要转换成wei使用parseEther，系统获取的wei，需要转换成eth使用formatEther，链上余额是 wei单位的 bigint，必须用 formatEther 转成字符串才能给用户看，parseFloat + toFixed(4) 是为了固定显示 4 位小数
3. useWaitForTransactionReceipt通过hash监听交易结果，等待交易成功，返回交易结果，如果交易失败，返回失败信息，执行过程txHash state 变化 → React 重渲染 → useWaitForTransactionReceipt 重新执行 → 拿到新 hash → 启用查询 → 内部 TanStack Query 轮询直到拿到 receipt
